Файловете съдържат ВСИЧКО досега, включително:

СЪДЪРЖАНИЕ
----------
Главна папка (качва се на хостинга/Netlify):
  nb-method-home.html    -> преименувай на index.html
  nb-method-login.html   -> вход (праща по роля)
  nb-method-app.html     -> клиентско приложение
  nb-method-coach.html   -> треньорски панел
  form.html              -> формуляр „Запиши се"
  + hero.jpg (твоя снимка), + файловете от pwa/

sql/ — В ТОЗИ РЕД при чиста инсталация (всички са безопасни
за повторно пускане; при работеща база пусни само новите):
  01-schema-v2 … 09-progress  (както досега)
  10-inquiries.sql        - заявките от формуляра
  11-checkins.sql         - „Как се чувстваш днес?"
  12-progress-photos.sql  - хранилище за прогрес снимки
  13-habits.sql           - навици + отметки
  14-why-note.sql         - „защо" колонка

pwa/ — мобилното приложение (иконки, manifest, sw.js)
extra/ — оферта, демо, Lovable план, PHP вариант на формуляра
         (hosting-form-handler.php + hosting-inquiries-mysql.sql
          за когато се преместите на cPanel хостинг)

СЛЕД РАЗАРХИВИРАНЕ
-------------------
1. Ключовете (Ctrl+F -> PASTE) на ЧЕТИРИ места:
   login, app, coach, form  (home няма нужда)
2. Провери в login: CLIENT_APP/COACH_APP сочат точните имена.
3. В Supabase -> Authentication -> URL Configuration сложи
   адреса на сайта (за линка „Забравена парола").
4. Netlify: Forms -> nb-inquiry -> Email notification -> имейл
   на Недко (за известията от формуляра).
5. Часовете на чата се сменят в app файла: CHAT_HOURS.

ЧЕСТИ ПРОБЛЕМИ — виж и стария списък:
- "Invalid supabaseUrl" = ключовете липсват в ТОЗИ файл
- RLS грешка = ролята coach не е зададена или политика липсва
- Бавно първо зареждане = безплатният Supabase се събужда
